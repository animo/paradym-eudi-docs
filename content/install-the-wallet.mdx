# Install the Wallet

For the public, stable, version of the Paradym Wallet you can download the app for:
-  [iOS](https://apps.apple.com/nl/app/paradym-wallet/id6449846111?l=en) 
- [Android](https://play.google.com/store/apps/details?id=id.paradym.wallet) 

Some pilot projects might require a beta release with experimental features implemented. This is a different version of the Paradym wallet application. If relevant, install instructions can be found on the project specific pages in these docs.
