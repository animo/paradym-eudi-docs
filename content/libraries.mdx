# Open-source libraries

An overview of other, more low-level, open-source libraries we have created or actively develop on and maintain. 

## Open Wallet Foundation Projects


- [Credo](https://github.com/openwallet-foundation/credo-ts) - TypeScript framework to build verifiable credential based solutions
- [OpenID4VC](https://github.com/openwallet-foundation-labs/oid4vc-ts) - Low level OpenID4VCI / OpenID4VP implementation in TypeScript
- [DCQL](https://github.com/openwallet-foundation-labs/dcql-ts) - TypeScript implementation of the DCQL query language
- [OpenID Federation](https://github.com/openwallet-foundation-labs/openid-federation-ts) - TypeScript implementation of OpenID Federation


## Other

- [Expo mDOC Data Transfer](https://github.com/animo/expo-mdoc-data-transfer) - React Native library for in-person proximity presentation of mDOCs
- [Expo Digital Credentials API](https://github.com/animo/expo-digital-credentials-api) - React Native library to add support for W3C Digital Credentials API
- [Expo Secure Environment](https://github.com/animo/expo-secure-environment) - React Native library to integrate with iOS and Android Secure Element 
- [EUDI Wallet Functionality](https://github.com/animo/eudi-wallet-functionality) - EUDI specific extensions for Credo (e.g. RP A&A)
- [mDOC](https://github.com/animo/mdoc) - TypeScript implementation of mDL/mDOC specification
- [Animo EUDI Wallet SDK (early Alpha)](https://www.npmjs.com/package/@paradym/wallet-sdk?activeTab=readme) - A Typescript SDK for building cross-platform Wallet applications in React Native
